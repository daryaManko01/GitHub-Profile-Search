# GitHub User Finder

A simple web application that allows users to search for GitHub profiles and display public information using the GitHub REST API.

## Overview

This project was created to practice working with APIs, asynchronous JavaScript, and DOM manipulation. Users can enter a GitHub username and view public profile information retrieved directly from GitHub.

## Features

- Search GitHub users by username
- Display user avatar
- Display name and username
- Show user bio
- Display public repositories count
- Show followers and following statistics
- Display location, company, and blog information
- Handle missing profile data with fallback values

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- GitHub REST API
